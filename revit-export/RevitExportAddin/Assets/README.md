# Revit Export Assets

Place real Revit assets here before packaging the APS AppBundle:

- `OurApp_RevitExportTemplate.rte`
- `Families/OurApp_Door_Single.rfa`
- `Families/OurApp_Door_Double.rfa`
- `Families/OurApp_Window_Fixed.rfa`
- `Families/OurApp_Window_Sliding.rfa`
- `Families/OurApp_Window_Generic.rfa`
- `Families/OurApp_Column_Rectangular.rfa`
- `Families/OurApp_Column_Round.rfa`
- `SharedParameters/OurApp_SharedParameters.txt`

These files must match the `APS_REVIT_ENGINE` Revit version. This repository intentionally does not include fake `.rte` or `.rfa` binaries.
